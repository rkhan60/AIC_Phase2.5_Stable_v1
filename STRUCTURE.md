# AI Consult Model Structure

## Core Components

### /core/engine/
- `logic_engine.py` - Main AI processing engine (60KB version from SC)
- `aic_system.py` - Core AIC system implementation
- `data_processor.py` - Data processing pipeline

### /core/analysis/
- `data_analyzer.py` - Advanced data analysis
- `crm_analysis.py` - Customer relationship analysis
- `business_insights.py` - Business intelligence generation

### /core/data/
- `data_processor.py` - Data processing utilities
- `test_data_generator.py` - Test data generation

### /core/interface/
- `app.py` - Main application interface
- `launch_aic.py` - AIC system launcher
- `business_viz_interface.py` - Business visualization

### /core/ml_agents/
- Base agent and specialized ML agents
- Model orchestration
- Agent coordination
